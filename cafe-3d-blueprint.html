1. Vision & Architecture Hybrid 3D + Commerce

Objective: Build a fast, high-converting commercial cafe website that integrates your downloaded 3D elements directly into the storefront while keeping checkout, table reservations, and inventory management effortless. The physical cafe's aesthetics (colors, textures, warm lighting, cup/bag branding) are mirrored in both the UI and the 3D shaders/lighting.

Frontend & 3D Layer

  • Next.js (App Router) + TypeScript
  • Tailwind CSS (Theme mapped to cafe palette)
  • React Three Fiber v9 + @react-three/drei
  • Zustand (Syncs 2D UI state ↔ 3D models)
  • GSAP / Framer Motion (Scroll triggers)

Backend & Business Logic

  • Supabase (PostgreSQL, Auth, Realtime, Storage)
  • Next.js Route Handlers (Server-side pricing & webhooks)
  • Razorpay (UPI, Cards, Netbanking for India)
  • WhatsApp / Email Alerts (Order tickets to barista)

3D Tooling & Hosting

  • Blender (Texture swap & aesthetic matching)
  • @gltf-transform/cli (Draco + WebP compression)
  • gltfjsx (Auto-generate typed React components)
  • Vercel (SSR + Edge CDN caching for .glb)

2. Downloaded 3D Assets & Aesthetic Pipeline Blender → WebGL

Since you already have 3D elements downloaded, do not drop raw downloaded files straight into /public. Raw assets are often 10MB–50MB and lack the cafe owner's branding. Follow this 4-step pipeline to connect them aesthetically and keep load times under 1.5 seconds.

Step 1Audit Format (.glb/.fbx) & Mesh Names
→
Step 2Apply Cafe Textures & Logo in Blender
→
Step 3Compress via gltf-transform
→
Step 4Convert to TSX via gltfjsx
Crucial Rule for Dynamic 3D Configurators: If a downloaded 3D coffee bag or cup has separate parts (e.g., Lid, CupBody, LogoSleeve) that you want to change colors/textures on dynamically when a user clicks a flavor variant, pass --no-join during optimization so meshes aren't merged together!

Terminal Commands for Your Downloaded Models

# 1. Inspect polycount, textures, and mesh names inside your downloaded model
npx @gltf-transform/cli inspect raw-downloads/coffee-cup.glb

# 2. Optimize geometry (Draco) & resize textures to 1024px WebP
# Remove --no-join ONLY for static decorative models (croissants, beans)
npx @gltf-transform/cli optimize raw-downloads/coffee-cup.glb public/models/coffee-cup.glb --compress draco --texture-compress webp --texture-size 1024 --no-join

# 3. Generate a strongly typed React Three Fiber component
npx gltfjsx public/models/coffee-cup.glb --types --draco -o src/components/3d/models/CoffeeCupModel.tsx

How to Connect Physical Cafe Aesthetics to Your 3D Models

1. Material & Branding Sync

  • Open the downloaded .glb/.fbx in Blender and export its UV layout.
  • Overlay the cafe's real logo, typography, and roast notes onto the cup sleeve or coffee bag texture in Figma/Photoshop.
  • Adjust Roughness (e.g., 0.8 for matte kraft paper bags, 0.15 for ceramic mugs, 0.05 for glass iced coffee).

2. Lighting & Environment Calibration

  • Match the cafe's interior mood using Drei's <Environment preset="apartment" /> or a custom warm HDRI.
  • Add a warm directional key light (#ffdfb8) + subtle rim light matching the cafe's pendant lamps.
  • Extract 3–4 hex colors from real cafe photos into CSS variables (--cafe-espresso, --cafe-cream, --cafe-brass).

Flow B: 3D-to-Business-Logic State Binding (Zustand)

How clicking a 2D menu/variant button updates both the 3D scene and the commercial cart payload simultaneously:

// src/store/useCafeStore.ts
import { create } from "zustand";

interface CartItem {
  productId: string;
  variantId: string;
  name: string;
  price: number;
  qty: number;
  customizations?: Record<string, string>;
}

interface CafeState {
  // 3D Aesthetic & Preview Sync
  activeHeroDrink: "espresso" | "iced-latte" | "matcha";
  selectedBeanTextureUrl: string;
  isLiteMode: boolean; // Auto-enabled on low-end mobile GPUs
  setActiveHeroDrink: (drink: "espresso" | "iced-latte" | "matcha") => void;
  setSelectedBeanTexture: (url: string) => void;
  toggleLiteMode: (val: boolean) => void;

  // Commercial Cart Logic
  cart: CartItem[];
  addToCart: (item: CartItem) => void;
  removeFromCart: (variantId: string) => void;
  clearCart: () => void;
}

export const useCafeStore = create<CafeState>((set) => ({
  activeHeroDrink: "espresso",
  selectedBeanTextureUrl: "/textures/roast-house.webp",
  isLiteMode: false,
  setActiveHeroDrink: (drink) => set({ activeHeroDrink: drink }),
  setSelectedBeanTexture: (url) => set({ selectedBeanTextureUrl: url }),
  toggleLiteMode: (val) => set({ isLiteMode: val }),

  cart: [],
  addToCart: (item) =>
    set((state) => {
      const existing = state.cart.find((i) => i.variantId === item.variantId);
      if (existing) {
        return {
          cart: state.cart.map((i) =>
            i.variantId === item.variantId ? { ...i, qty: i.qty + item.qty } : i
          ),
        };
      }
      return { cart: [...state.cart, item] };
    }),
  removeFromCart: (variantId) =>
    set((state) => ({ cart: state.cart.filter((i) => i.variantId !== variantId) })),
  clearCart: () => set({ cart: [] }),
}));

SSR-Safe 3D Wrapper Pattern (Next.js)

Wrap every 3D scene using dynamic(..., { ssr: false }) and a fallback image for low-power devices:

// src/components/3d/SceneWrapper.tsx
"use client";
import dynamic from "next/dynamic";
import { Suspense } from "react";
import { useCafeStore } from "@/store/useCafeStore";

const HeroCupCanvas = dynamic(() => import("./HeroCupScene"), {
  ssr: false,
  loading: () => <div className="h-[420px] animate-pulse bg-stone-900/40 rounded-xl" />,
});

export default function SceneWrapper({ fallbackImg }: { fallbackImg: string }) {
  const isLiteMode = useCafeStore((s) => s.isLiteMode);
  if (isLiteMode) return <img src={fallbackImg} alt="Cafe Signature" className="rounded-xl" />;

  return (
    <Suspense fallback={<img src={fallbackImg} alt="Loading 3D..." />}>
      <HeroCupCanvas />
    </Suspense>
  );
}

PostgreSQL / Supabase Core Schema

-- Run inside Supabase SQL Editor
CREATE TABLE categories (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  slug TEXT UNIQUE NOT NULL,
  icon_3d_model TEXT -- optional path e.g. '/models/icon-pastry.glb'
);

CREATE TABLE products (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  category_id UUID REFERENCES categories(id) ON DELETE SET NULL,
  name TEXT NOT NULL,
  description TEXT,
  image_url TEXT NOT NULL,
  model_3d_url TEXT,           -- e.g. '/models/coffee-bag.glb'
  is_featured_3d BOOLEAN DEFAULT false,
  in_stock BOOLEAN DEFAULT true,
  is_veg BOOLEAN DEFAULT true, -- Important for Indian cafe menus
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE product_variants (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  product_id UUID REFERENCES products(id) ON DELETE CASCADE,
  label TEXT NOT NULL,         -- e.g. '250g Whole Bean', 'Large Iced'
  price_paise INTEGER NOT NULL, -- Store INR in paise (₹250 = 25000)
  texture_override_url TEXT,   -- Swaps 3D model label dynamically on click!
  color_hex TEXT
);

CREATE TABLE cafe_tables (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,          -- e.g. 'Window Booth 1', 'Garden Table 4'
  zone TEXT NOT NULL,          -- 'indoor' | 'patio' | 'bar'
  capacity INTEGER NOT NULL,
  preview_3d_camera_pos JSONB  -- Optional camera focus coordinates
);

CREATE TABLE reservations (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  table_id UUID REFERENCES cafe_tables(id),
  customer_name TEXT NOT NULL,
  customer_phone TEXT NOT NULL,
  guest_count INTEGER NOT NULL,
  slot_start TIMESTAMPTZ NOT NULL,
  slot_end TIMESTAMPTZ NOT NULL,
  status TEXT DEFAULT 'confirmed' -- 'confirmed' | 'cancelled' | 'seated'
);

CREATE TABLE orders (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  customer_name TEXT NOT NULL,
  customer_phone TEXT NOT NULL,
  fulfillment_type TEXT NOT NULL, -- 'pickup' | 'delivery' | 'dine_in'
  delivery_address TEXT,
  total_paise INTEGER NOT NULL,
  razorpay_order_id TEXT UNIQUE,
  razorpay_payment_id TEXT,
  payment_status TEXT DEFAULT 'pending', -- 'pending' | 'paid' | 'failed'
  order_status TEXT DEFAULT 'new',       -- 'new' | 'preparing' | 'ready' | 'completed'
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE order_items (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_id UUID REFERENCES orders(id) ON DELETE CASCADE,
  variant_id UUID REFERENCES product_variants(id),
  quantity INTEGER NOT NULL,
  unit_price_paise INTEGER NOT NULL,
  customizations JSONB
);
